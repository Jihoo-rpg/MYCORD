Windows와 Mac

설치 파일 하나로 컴퓨터에 앱처럼 깔려요.

설치는 이렇게

Windows

  1. Mycord-Setup.exe를 받아서 실행하세요.
  2. “Windows의 PC 보호” 창이 뜨면 추가 정보 → 실행을 누르세요.
  3. 설치가 끝나면 Mycord를 열고 가입하세요.

이 창도 Microsoft에 유료로 등록하지 않은 앱이면 항상 떠요.

Mac

  1. Mycord.dmg를 열고 Mycord를 응용 프로그램 폴더로 끌어다 놓으세요.
  2. Mycord를 실행하면 “열지 않음” 경고가 떠요. 휴지통으로 이동은 누르지 말고 완료를 누르세요.
  3. 왼쪽 위 사과 메뉴 → 시스템 설정 → 개인정보 보호 및 보안으로 가서, 맨 아래 보안 칸의 그래도 열기를 누르세요.
  4. 맥 비밀번호나 Touch ID를 입력하고 열기를 누르면 끝이에요. 다음부터는 그냥 열려요.

이 경고는 앱이 위험해서가 아니라, 애플에 유료로 등록(서명)하지 않은 앱이면 항상 떠요.
